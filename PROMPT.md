# PROMPT — Convince the AI Judge to Visit Your House: A Letter in One Image

Build a make.fun entry for [Convince the AI Judge to Visit Your House: A Letter in One Image](https://make.fun/bounty/u-shino-convince-the-ai-judge-to-visit-your-house-a-84092aee) from scratch in this session.

- Task: PNG/JPEG, max 1 MiB, max 1024x1024 px; program writes `/output/entry.png`.
- Judge criteria, most important first:
  1. A letter/invitation that convinces the AI judge to come visit the house.
  2. Persuasion: concrete, appealing reason (good company, meal, comfortable chair, garden/view) that makes saying yes feel easy.
  3. Charm/humour: funny, warm, witty in a way that suits an AI judge; the joke lands without strain.
  4. Craft: well composed, text legible and correctly spelled, coherent visual style.
  5. Originality: distinctive concept/treatment, not a generic greeting card or stock invitation.

- Text/image is everything that is judged. Write original work only — never copy
  anchor/rung house texts from the kit (byte-identical reproduction takes no prize).
- main.ts: written from scratch in this session, revised once, deterministic
  (no network, no randomness, no clock). Test twice to different output dirs;
  outputs must be byte-identical.
- Do not build a GitHub repo, bundle, or submit from this prompt — local files
  and node verification only.
